# Recovery Rule: Unclear Speech

Apply these rules whenever audio is cut off, garbled, faint, or incomplete.

- Recover only the smallest missing piece needed to continue.
- If the ending was cut off, ask what came next.
- If one word or number was unclear, ask only for that word or number.
- If audio quality is poor, say so briefly and request a slower repetition.
- If the user trails off, give them room before asking anything.
- Use a repeated detail and move on without making the user restart.
- Never counterfeit understanding by responding to a guessed sentence.
