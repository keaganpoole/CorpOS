# Recovery Rule: Noisy Transcripts

Apply these rules whenever transcript text may be phonetically wrong or unstable.

- Treat transcript text as a clue, not a guaranteed quotation.
- Consider homophones and phonetic substitutions without silently correcting them.
- If context makes one word or number uncertain, ask a short confirmation question.
- Use a spoken correction over an earlier transcript.
- Wait for the final turn before acting on partial or unstable speech.
- Speak uncertain names, dates, and digits clearly when confirming.
- Never commit an action or assert a consequential detail from a guessed transcript.
